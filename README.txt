Financial Market Prediction Prototype

This Streamlit app is a prototype developed for Aron Belle's final year dissertation project that investigates ML approaches for short-term financial market direction prediction.

Features:
- Live stock ticker input using Yahoo finance data
- XGBoost-based market direction prediction
- prediction confidence display
- recent closing price graph
- model comparison and feature importance summary for transparency

DISCLAIMER:
this app is not for financial advice. it is for educational and research purposes. It is nowhere near accurate enough to be financial advice anyway.

How to run locally:

```bash
pip install -r requirements.txt
streamlit run app.py
